# Neural Scene Representation and Neural Rendering — Fall 2026

This is the deliberately simple 2026 version of the 2025 course website. It keeps the same four-page, hand-written HTML/CSS structure and has no framework, database, search interface, or build step.

You do not need a new personal GitHub account. For the clean address `https://neural-representation-2026.github.io/`, use your existing account to create the organization `neural-representation-2026`, then create the public repository `neural-representation-2026.github.io` inside it.

## Before publishing

Search the four HTML files for `TBD` and update:

- the second TA's name (and add webpages/emails if desired)
- meeting time and room
- paper sign-up sheet
- paper-question form
- presentation-slide folder
- presentation assignments and dates

The reading list is rendered in `topics.html`, generated from the Google sign-up sheet linked on the Organization page.

## Upload to GitHub Pages

Unzip the package, then upload its contents to the repository root. In GitHub choose **Settings → Pages → Deploy from a branch → main → /(root)**. `index.html` must remain at the repository root.
